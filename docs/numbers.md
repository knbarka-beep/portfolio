# Where each project number comes from

Every number on a project page, with the file it comes from and the exact words in that file. Paths are relative to the folder that holds the three project repos. `tests/numbers.test.mjs` checks that every number on a project page (in all three languages) is in this table, and, when the project repos sit next to this one, that each quote is really in its source file and contains the number.

Years in dates (2025 to 2028) are listed too, so the test covers them.
